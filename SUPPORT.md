# Support

This repository is a private DPN Technology project.

## Bugs
Use the repository Bug Report issue form with the version, affected component, reproduction steps, expected behavior, and sanitized evidence.

## Features
Use the Feature Request issue form and describe the user/operational goal, proposed outcome, preferred extension layer, security/approval impact, and acceptance criteria.

## Security
Do not report sensitive vulnerabilities through a normal issue. Follow `SECURITY.md`.

## Pull Requests
Follow `CONTRIBUTING.md`. CI should pass before a change is treated as release-ready.

## Releases
See `RELEASE_PROCESS.md` for versioning, validation, tagging, artifact, and rollback expectations.
