# DPN AI Plugin Examples

Files ending in `.example` are not loaded. Review the source, copy the chosen file into `plugins/`, remove the `.example` suffix, configure any required environment variables, and restart DPN AI.

- `fivem_workspace_tools.py.example`: discovers FiveM resources and parses manifests inside the restricted workspace.
- `discord_webhook.py.example`: posts explicitly requested announcements to a configured Discord webhook.

Plugins are trusted local code. Review them before enabling them.
