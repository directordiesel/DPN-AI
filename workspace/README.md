# DPN AI Restricted Workspace

Put projects and reference files in this folder. All built-in file tools are confined here.

- `uploads/` receives files uploaded through the interface.
- `generated/` receives Word, PDF, Excel, PowerPoint, image, and conversation-export files.
- Project records can point to any folder beneath this workspace.
- Create a verified snapshot before broad code or content changes.
- Keep an external backup of this folder and `data/`.
