# Projects and Task Boards

Projects let DPN AI preserve mission context between conversations.

Each project stores:

- Name and description.
- Workspace root.
- Active, paused, completed, or archived status.
- Task board and task results.
- Related operation runs.

Task states are backlog, ready, running, blocked, done, and failed. Priorities are low, normal, high, and critical.

Select a project in the top bar before chatting. Its mission, root path, and current task list are injected into the agent context. The agent can create and update tasks through tools.
