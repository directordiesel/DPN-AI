## Validation

The v6 integration was merged from PR #24 after CI, DPN Security Gate v2, and Runtime & Recovery Assurance all passed on the validated v6 head. The stable merge commit is `82a8629f858476f0f9bd10beefd0caf529a1d3e3`.

## Security and reliability

The release preserves workspace confinement, safe command and package controls, sensitive-environment stripping, approval boundaries, browser/network protections, bounded archive/media handling, connector host/method confinement, MCP allowlists, vault-only secret handling, persistent recovery semantics, automation authorization, and explicit release gates.
