## Product Snapshot

**Current release:** v5.0.7 — Adaptive Interface and Sentinel HD  
**Publisher:** DPN Technology  
**Primary stack:** Python · Local AI · Missions · Tools · Voice · MCP  
**Development state:** Active

DPN AI is built as an execution platform rather than a chat-only interface. It combines conversational AI with persistent missions, project workspaces, memory, knowledge indexing, document/media tooling, background jobs, approvals, plugins, HTTP connectors, MCP integration, model routing, and local voice capabilities.

## What Makes It Different

- Local-first architecture with explicit execution boundaries
- Persistent multi-step missions and recoverable checkpoints
- Approval-aware tools and external integrations
- Encrypted secret storage outside normal project data
- Project workspaces, memory, indexed knowledge, and provenance
- Extensible plugin, connector, MCP, browser, and desktop adapters
- Local voice input/output and Sentinel HD voice support
- Controlled artifact creation for documents, spreadsheets, presentations, PDFs, and media
- Automated tests, CI, release evidence, and supply-chain documentation

## Execution Model

```text
Request
  -> Cognitive Kernel
  -> Goal Contract
  -> Specialist / Model Routing
  -> Context Assembly
  -> Policy + Approval Gates
  -> Tool / Mission Execution
  -> Evidence + Artifacts
  -> Persistent Result
```
